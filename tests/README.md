# Тесты для бота Кинопоиска

Этот каталог содержит тесты для проверки функциональности бота.

## Структура тестов

- `test_handlers.py` - Тесты для обработчиков команд бота
- `test_kinopoisk_api.py` - Тесты для API клиента Кинопоиска
- `test_config.py` - Тесты для конфигурации
- `test_integration.py` - Интеграционные тесты
- `conftest.py` - Общие фикстуры для всех тестов

## Установка зависимостей

Убедитесь, что установлены все зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

### Запуск всех тестов

```bash
pytest
```

### Запуск с подробным выводом

```bash
pytest -v
```

### Запуск конкретного файла тестов

```bash
pytest tests/test_handlers.py
```

### Запуск конкретного теста

```bash
pytest tests/test_handlers.py::test_cmd_start
```

### Запуск с покрытием кода

```bash
pytest --cov=. --cov-report=html
```

## Типы тестов

### Unit тесты

- `test_handlers.py` - Тестируют отдельные обработчики команд
- `test_kinopoisk_api.py` - Тестируют методы API клиента
- `test_config.py` - Тестируют конфигурацию

### Интеграционные тесты

- `test_integration.py` - Тестируют полные потоки взаимодействия

## Фикстуры

В `conftest.py` определены общие фикстуры:

- `bot` - Экземпляр бота для тестирования
- `dispatcher` - Диспетчер для обработки сообщений
- `user` - Тестовый пользователь
- `chat` - Тестовый чат
- `message` - Тестовое сообщение
- `callback_query` - Тестовый callback query
- `state` - FSM контекст для тестирования состояний
- `mock_kinopoisk_api` - Мокированный API клиент

## Примечания

- Все тесты используют моки для изоляции от внешних зависимостей
- API клиент мокируется, чтобы не делать реальные запросы к Кинопоиску
- Тесты не требуют реальных токенов для работы
